# Firmware validation data set

`firmware_validation.zip` is the data behind OpenWebNet-HA/OWNd pull request 86
(branch `fix/firmware-validated-who4-who0-who25`): the report, the replayed frames
per gateway program, results for MyHomeServer1, F454, F459, F461 and F450, the raw
client/bus/monitor logs, the harness scripts and the emitted-frame corpus.

The firmware images themselves are not included (BTicino property); the README
inside the archive says where to put them to reproduce the runs.

Direct link: https://github.com/gdluck/OWNd/raw/firmware-validation-data/firmware_validation.zip
